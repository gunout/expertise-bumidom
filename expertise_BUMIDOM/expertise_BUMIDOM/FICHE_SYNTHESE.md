# BUMIDOM — Fiche de synthèse

## Identification
- **Nom** : Bureau pour le développement des migrations intéressant les DOM
- **Création** : 1963
- **Dissolution** : 1982 (remplacé par l'ANT)
- **Zone** : Guadeloupe, Guyane, Martinique, Réunion vers Métropole
